# COUNTERBEAT

Phonk 리듬에 맞춰 **4마디 피하고, 4마디 베는** 모바일 리듬 아케이드 보스전.

> 현재: 웹 프로토타입 v0.1 (PC 브라우저에서 마우스 드래그로 테스트, 모바일 터치도 동작)

## 실행

```bash
python -m http.server 5173
```

브라우저에서 `http://localhost:5173` → 탭해서 시작. **소리 켜고 플레이.**

## 홈 화면에 추가 (앱처럼 실행)

PWA 지원. 배포 주소(HTTPS)에서:
- **Android Chrome:** 메뉴 → `홈 화면에 추가` / `앱 설치`
- **iOS Safari:** 공유 → `홈 화면에 추가`

전체 화면·세로 고정으로 실행되고, 한 번 열면 곡까지 캐시돼서 오프라인에서도 플레이 가능.
코드/HTML은 네트워크 우선이라 배포하면 다음 실행 때 반영됨. **곡 파일을 바꾸면 `sw.js`의 `CACHE` 버전을 올릴 것.**
아이콘은 `python tools/make_icons.py`로 다시 생성.

## 화면 구성

```
로비 ──PLAY──▶ 스테이지 선택 ──START──▶ 게임 ──▶ 결과 (RETRY / STAGES)
 │  하단 탭바: SHOP(준비 중) · SETTINGS        │ 일시정지(왼쪽 위 ||): RESUME / RETRY / STAGES
 └ 설정 오버레이                              
```

- **로비:** 로고 + PLAY. 하단 탭바는 `ui.js`의 `LOBBY_TABS`에 항목만 추가하면 늘어남 (상점·메뉴 자리).
- **스테이지 선택:** 카드를 좌우로 드래그해서 넘김 (놓으면 스냅, 빠르게 휙 넘기면 한 장). 옆 카드·화살표 탭도 가능. 카드에 스테이지별 BEST·RANK.
- 스테이지 목록은 `songs.js`의 `STAGES` (`locked: true`면 잠금 카드). 기록은 스테이지별 localStorage `cb_best_<id>`, `cb_rank_<id>`.
- 메뉴 버튼은 즉시 모드: 그릴 때 `button()`이 터치 영역을 등록 → 손 뗄 때 실행. 새 화면은 `ui.screen` 값 추가 + `drawMenu`에서 그리기.

### 로비 BGM

- `music/0. Lobby.mp3` (75 BPM). 로비·설정·스테이지 선택에서 재생, START 누르면 0.6초 페이드아웃 → 스테이지 곡.
- 처음 켤 땐 인트로부터, 그 뒤로 4~27마디(24마디, 76.8초)를 끊김 없이 무한 반복. 이음새는 킥 직전에 40ms 크로스페이드를 미리 입힘 (`songs.js`의 `MENU_MUSIC`, `audio.js`의 `bakeLoop`).
- 결과/일시정지에서 STAGES로 돌아오면 루프 구간부터 페이드인. 음악 볼륨 설정 적용. 앱을 나가면(백그라운드) 멈춤.
- 브라우저 자동재생 제한 때문에 첫 터치 후에 시작됨.

## 플레이 방법

- **이동:** 화면 아무 곳이나 드래그(상대 이동, 손가락에 캐릭터가 안 가려짐). 이동 감도·이동 가속은 설정에서 조절. PC는 마우스 트래킹(드래그 없이 커서를 따라감)도 가능.
- **DODGE (4마디):** 보스 탄막을 피함. 탄을 아슬아슬하게 스치면 **GRAZE 게이지**가 참.
- **COUNTER (캐치 포인트):** 4마디째 마지막 박에 음악이 끊기고 탄막이 멈춤. 다음 박에 드롭.
- **STRIKE (4마디):** 화면이 흑백 반전. 박자마다 생기는 약점 노드를 **드래그로 그어서** 벰.
  - 노드는 1.5박 전(FINISH는 2.5박 전)부터 보임
  - 순서 표시: 다음 노드는 진하게 + 박마다 맥동, 그다음은 반투명, 그 뒤는 흐리게. 다음 → 그다음 노드로 점선 화살표
  - 위치는 랜덤, 최소 여백: 정박 노드끼리 지름 1개, 4연타끼리 지름 0.5개, 보스(FINISH 자리)와 지름 1개
  - 정박 ±0.25초 안에 그으면 판정. ±0.11초 PERFECT / ±0.18초 GREAT / 나머지 GOOD. 결과 카드에 평균 타이밍(+늦음/−빠름) 표시 → LATE면 설정의 싱크 보정을 −쪽으로, EARLY면 +쪽으로
  - 마지막 마디는 8분 4연타 후 3박째 FINISH (보스 본체를 그어서 벰). 4연타는 관절 내각 150~170°로 한쪽으로 휘는 곡선, 두 번째 꺾임은 첫 꺾임 ±3° 이내 (지그재그 없음)
  - 대미지 = 판정 × GRAZE 배율 × 콤보
- **특별 구간** (곡이 4마디 단위와 어긋나는 곳만, 전부 4박 기준):
  - **SPLIT 반격:** 배경 전체가 은은하게 붉게 맥동(세로 WARNING 글자, 아무것도 안 가림) + 경보음 → 반격 박을 2분 → 4분 → 8분 4연타 ×2 → 8분 4연타 + FINISH로 점점 쪼갬
  - **WARNING 회피:** 회피 구간 마지막 4마디 시작에 경고만 (8마디 회피면 뒤쪽 4마디)
  - **FINAL:** 곡 끝 마지막 반격. 1마디면 4연타 + FINISH, 4마디면 2배 비트 + FINISH
- **반격 패턴** (8분 그리드, 1 = 노드):
  | 번호 | 이름 | 리듬 (마디별 8분) | 노드 |
  |---|---|---|---|
  | 1 | 기본 | `10101010` ×3 → `1111F` | 17 |
  | 2 | 클랩 더블 (`p2`) | `10111011` ×3 → `1111F` (쿵·딱딱·쿵·딱딱, 곡 클랩과 같이) | 23 |
  | 3 | SPLIT (`split`) | `10001000` → `10101010` → `11111111` → `1111F` | 19 |
  | 4 | 2배 비트 (`x2`) | `11111111` ×3 → `1111F` | 29 |
  - 1스테이지 배치(고정): `1 1 1 1 2 2 → 3 → 4 ×6 → FINAL`. 랜덤 대신 고정이라 외워서 실력이 늚
  - 패턴 1·2는 1스테이지 전용 (재탕 안 함). 2스테이지부터는 **차트**(`songs.js`의 `chart`)가 반격 박자를 정함 (아래)
  - 2스테이지 리듬 (구간마다 새 리듬, 16분 = 1칸):
    | 마디 | 이름 | 느낌 |
    |---|---|---|
    | 9 / 17 / 25 | BUILD · 3-3-2 · 3-3-2+ | 2분 → 4분 / 트레실로(3+3+2) / 트레실로 + 8분 꼬리 |
    | 33 / 41 | OFFBEAT · KICK-BASS | 뒷박(리버스 베이스 자리) / 1·3박에 둥둥 |
    | 53 / 61 | GALLOP · GALLOP-OFF | 다다다 · 다다다 (8분 셋 묶음) / 뒷박 쪽으로 밀린 셋 묶음 |
    | 69 (WARNING) | ECHO | 점8분 메아리, 조용한 브레이크다운 |
    | 77 / 85 | STAB · STAB+ | 스탭 + 점8분 꼬리 / 더 촘촘하게 |
    | 93 / 101 / 109 | SCREECH · STOP&GO · SCREECH+ | 점8분 3:4 폴리리듬 / 8분 몰아치기 ↔ 1마디 정지 / 섞어서 |
    | 117 | DECEL | 8분 → 4분 → 2분 (곡이 가라앉는 구간) |
    | 125 / 133 | SYNCOPA · ROLL-OFF | 2·4박 정박 비우는 싱코페이션 / 4연타 + 뒷박 |
    | 141 (WARNING) | RISE | 2분 → 점4분 → 8분으로 점점 빨라짐 |
    | 149 FINAL | FINAL RUSH | 8분 몰아치기 (2마디째만 숨 한 번) |
  - 3스테이지 리듬 (하프타임 트랩이라 **셋잇단** 처음 등장. `x.33`·`x.67` = 16분 칸 사이 셋잇단 위치):
    | 마디 | 이름 | 느낌 |
    |---|---|---|
    | 8 / 16 / 24 / 32 | STEP-IN · TRIPLET 4 · HAT ROLL · TOLL | 하프타임 쿵·딱 / 4분 셋잇단 / 3박째 하이햇 셋잇단 롤 / 종소리처럼 띄엄띄엄 |
    | 40 / 48 (드롭1) | 808 SLIDE · KICK ROLL | 3-3 뒤 4분 셋잇단 / 첫 박 셋잇단 킥 롤 |
    | 56 / 64 | SWING · CROSS | 점16분 스윙 (따-닥 따-닥) / 4분 셋잇단만으로 박 엇갈리기 |
    | 72 | HEARTBEAT | 두-근 (셋잇단 한 쌍), 조용한 브레이크다운 |
    | 84 / 92 / 100 (WARNING 뒤) | TRIPLET RUN · STORM · STUTTER | 1~2박 셋잇단 질주 / 셋잇단 4연타 ×2 / 16분 더듬기 |
    | 108 / 116 | CROSS+ · SWING+ | 셋잇단 섞기 / 스윙 + 4분 셋잇단 |
    | 128 / 136 | CHECKMATE · FINAL | 파이널 드롭 몰아치기 / 마지막 임팩트 1마디 |
- **차트 (`chart`):** 반격 구간마다 16분 위치 목록. 위치는 게임이 랜덤 배치하니 박자만 정함. [editor.html](editor.html)에서 곡과 같이 클릭음으로 듣기·칸 클릭 수정·탭 녹음 가능.
  - 구간의 마지막 탭 = FINISH. 앞 노드와 8분 이하 간격이면 연타(4연타처럼 한쪽으로 10~30° 휘며 이어짐, 4개마다 새 곡선), 아니면 정박 노드 배치
  - 차트가 있으면 섹션 라벨(`x2`·`split`·`final`)은 회복 규칙·WARNING 연출에만 쓰이고, 차트가 없는 구간만 라벨 패턴으로 나옴
  - 마지막 마디 3박 16분 뒤까지만 넣을 수 있음 (4박째에 반격 정산)
- **2배 비트 (x2):** WARNING(SPLIT)을 넘긴 뒤 반격은 전부 4분음표 자리가 8분 4연타로 (반격당 노드 17 → 29개). 반격 중엔 맞을 일이 없으니 빠른 대신 대미지 기회가 많음. 길어진 연타는 베기 음계가 순환
- **일시정지:** 왼쪽 위 `||` (PC는 ESC). 일시정지 중엔 화면을 완전히 가림 (멈춰놓고 패턴을 보며 예측하는 꼼수 방지).
- **체력 5칸.** 맞으면 1칸 감소 + 1.5초 무적 + 주변 탄 정리.
- **회복:** 체력 1칸 (꽉 차 있으면 +500점)
  - 보통 반격: 노드를 **하나도 안 놓치면(FULL COMBO)**. 전부 PERFECT면 **FULL PERFECT** 표시
  - WARNING 이후 어려운 반격(SPLIT·2배 비트·FINAL): **70% 이상 맞히고 FINISH는 반드시**
  - FINISH로 가는 화살표는 굵은 실선으로 박마다 맥동
- 보스 HP를 0으로 만들면 **BREAK!** → 그 반격의 FINISH까지 베고 클리어 (타격감용). 결과 기록(판정·콤보·점수·시간)은 처치 순간에 고정돼서 이후 미스는 기록에 안 남음.

### 등급 (클리어 시, 낮음 → 높음)

| 등급 | 조건 |
|---|---|
| C | 그 외 |
| B | 정확도 50% 초과 |
| A | 피격 3번 이하 + 정확도 70% 초과 |
| S | 피격 1번 이하 + 정확도 85% 초과 |
| **M** (MASTER) | 곡 전체 FULL COMBO (방울 MISS 0) |
| **L** (LEGEND) | 곡 전체 FULL PERFECT (방울 전부 PERFECT) |

정확도 = (PERFECT + GREAT×0.7 + GOOD×0.4) ÷ 전체 방울. 보스 처치 이후 방울은 기록에 안 들어감.

### 난이도 메모
- 탄 실제 판정은 보이는 크기의 60% (`BULLET_HIT`), 레이저 판정 폭은 80%.
- 레이저 예고 2박(0.8초), 블라스트 예고 2박.
- 난이도 단계(tier)는 곡마다 `songs.js`의 `tierBars`마디마다 상승, `maxTier`까지 (첫 곡: 36마디마다, 최대 2). 링 탄 개수·속도 증가, 레이저 추가.
- 1스테이지: 보스 HP 3000 (전부 PERFECT 기준 그레이즈 x1.5면 SPLIT쯤, 그레이즈 없이도 72마디 2배 비트 반격쯤 처치), 최대 tier 2.
- 3스테이지 STALEMATE (난이도 별 2, 체감 2.5 = 2스테이지보다 조금 어렵게): 보스 HP 3400 (그레이즈 없이 전부 PERFECT면 92마디 반격쯤 처치), 36마디마다 tier 상승, 최대 2. 반격 16번, 약 3분 40초.
- **회피 탄막 세기 (`power`, 곡마다):** tier와 별개로 스테이지 난이도만큼 회피 패턴이 늘어남
  | | 1스테이지 (1) | 2스테이지 (2) | 3스테이지 (2.5) |
  |---|---|---|---|
  | 블라스트 (회피 4마디당) | 1 | 2 | 3 (좌우 번갈아 3마디 연속) |
  | 레이저 (tier 0, 4마디당) | 4 | 7 | 8 |
  | 조준탄 (빌드업 마디) | 6 | 7 | 9 |
  | 링 탄 | 기본 | +2개 | +3개, 조금 빠르게 |
- **테마색:** 게임 중 강조색(보스·노드·레이저 예고·HUD)이 스테이지 색을 따름. 1 = 시안/빨강(반격), 2 = 빨강, 3 = 보라. 메뉴는 시안 그대로 (`STAGES`의 `color`·`strikeColor`)
- 2스테이지 (난이도 별 2, 1스테이지보다 살짝 어렵게): 보스 HP 3000 (차트 기준 그레이즈 없이 전부 PERFECT면 93마디 반격쯤 처치), 40마디마다 tier 상승, 최대 2. 반격 18번, 약 4분.

## 음악 모드

- **기본: Suno 곡** (1스테이지 **CATCH POINT** = `music/1. CATCH POINT.mp3`, 2스테이지 **UNREACHABLE** = `music/2. UNREACHABLE.mp3`, 3스테이지 **STALEMATE** = `music/3. STALEMATE.mp3`). 곡이 음악을 맡고, 게임은 DJ 필터로 공수를 표현: 회피 중엔 곡이 살짝 먹먹(로우패스 1.8kHz), 캐치 박에 필터를 닫으며 빨아들이고, 드롭 박에 활짝 열면서 킥을 얹음. 설정에서 DJ 필터를 끄면 곡은 항상 원음, 드롭 킥만 남음.
  - 장애물 소리: 설정에서 선택 (기본 레이저 = Railgun, 블라스트 = Glitch Crush). [lab.html](lab.html)에서도 미리듣기. 레이저는 멜로디 없음, 세로 레이저는 위치 따라 패닝.
  - 구간(회피/반격)은 [songs.js](songs.js)의 비트맵으로 정함: `[시작 마디, 타입]` 목록.
  - 회피 구간 마지막 마디 4박째 = 캐치 포인트. 반격 구간 마지막 마디 = FINISH. 회피는 보통 4마디 (곡 구조상 어긋나는 곳만 8마디).
  - 템포맵: Suno 곡은 템포가 조금씩 흔들림 → `tempo: [[마디, 파일초], ...]` 기준점 사이를 선형으로 이어서 게임 격자(150 BPM)를 곡에 맞춤. 없으면 `offset`(첫 박 초) + 고정 BPM.
  - 곡이 끝날 때까지 보스를 못 잡으면 TIME UP.
- 곡이 없는 스테이지는 내장 합성 비트로 대체 (`인트로 2마디 → [회피 4마디 → 캐치 → 반격 4마디] 반복`).

현재 게임 그리드는 150 BPM 고정 (곡도 150 BPM 근처여야 함, 흔들림은 템포맵이 흡수).

| 항목 | 값 | 기본 |
|---|---|---|
| 언어 | 한국어 / English / 日本語 / 中文 (현재 설정 화면 문구만) | 기기 언어 (그 외엔 English) |
| 전체 볼륨 | 0~100% | 70% |
| 음악 볼륨 | 0~100% (Suno 곡만) | 100% |
| 마우스 트래킹 (PC만 보임) | ON이면 드래그 없이 플레이어가 마우스 커서에 딱 붙어 따라감 (감도·가속 무시, 게임 중 커서 숨김) | OFF |
| 이동 감도 | ×1.0 ~ ×2.2 (0.1 단위, 손가락·마우스 이동량 배율). ×1.0 + 이동 가속 OFF = 마우스 피하기처럼 1:1 | ×1.6 |
| 이동 가속 | OFF / 약 / 중 / 강 (빠르게 휘두르면 최대 감도 × 1.75) | 중 |
| 레이저 소리 | Heavy Beam / Railgun / Plasma Zap / Reese Blast | Railgun |
| 블라스트 소리 | Original / Impact Boom / Metal Slam / Sub Drop / Glitch Crush / Thunder | Glitch Crush |
| DJ 필터 | ON / OFF | ON |
| 싱크 보정 | ±10ms 단위 | 0ms |

행의 왼쪽 절반 탭 = 이전 값, 오른쪽 절반 = 다음 값. 소리는 바꿀 때 미리듣기. 이 브라우저(localStorage)에 저장됨.
※ **블라스트 (BLAST)** = 화면 절반을 덮는 함정 (코드 안 이름은 `slam`).

## 키보드 (PC)

`ESC` 하나만: 게임 중 = 일시정지/이어하기, 메뉴 = 뒤로. 나머지는 전부 화면 터치/클릭.

## 구조

```
index.html   캔버스 + 스크립트 로드
lab.html     사운드 랩: 레이저/블라스트 소리 후보 미리듣기
manifest.webmanifest, sw.js, icons/   홈 화면 앱(PWA)
tools/       아이콘 생성 스크립트
audio.js     WebAudio 합성 phonk 키트 + 곡 재생/덕킹
songs.js     곡 비트맵 (BPM, 첫 박 오프셋 또는 템포맵, 구간 목록, 녹음 차트) + 스테이지 목록 + 곡 시간 변환
editor.html  맵 에디터: 곡 들으며 반격 박자 녹음 → chart 내보내기 (게임과 별개 도구 페이지)
music/       곡 파일
game.js      스테이지 로딩, 곡 구조, 스케줄러, 스폰, 판정, 렌더링, 입력
ui.js        메뉴 UI: 로비·스테이지 선택·설정·일시정지 버튼 + 버튼 시스템
docs/        기획/음악 문서
```

- 기준 시계는 `AudioContext.currentTime` (프레임 시간 아님). 일시정지 = 오디오 컨텍스트 suspend.
- 오디오는 0.15초, 게임 오브젝트는 1마디 앞서 예약. 탄/레이저는 시간 함수라 결정적.
- 논리 해상도 540×960 (9:16 세로), 화면에 맞춰 스케일.
- 구간 진행도는 HUD 대신 배경 전체 게이지로 표시. 끝선이 박마다 맥동, 캐치 직전 마디는 경고색.
- 구간 게이지: 회피는 왼→오로 차오르고, 반격은 오→왼으로 빠짐.
- Suno 모드의 장애물 소리는 스폰 시점에 오디오 시간으로 미리 예약.
