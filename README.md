# COUNTERBEAT

Phonk 리듬에 맞춰 **4마디 피하고, 4마디 베는** 모바일 리듬 아케이드 보스전.

> 현재: 웹 프로토타입 v0.1 (PC 브라우저에서 마우스 드래그로 테스트, 모바일 터치도 동작)

## 실행

```bash
python -m http.server 5173
```

브라우저에서 `http://localhost:5173` → 탭해서 시작. **소리 켜고 플레이.**

## 홈 화면에 추가 (앱처럼 실행)

PWA 지원. 배포 주소(HTTPS)에서:
- **Android Chrome:** 메뉴 → `홈 화면에 추가` / `앱 설치`
- **iOS Safari:** 공유 → `홈 화면에 추가`

전체 화면·세로 고정으로 실행되고, 한 번 열면 곡까지 캐시돼서 오프라인에서도 플레이 가능.
코드/HTML은 네트워크 우선이라 배포하면 다음 실행 때 반영됨. **곡 파일을 바꾸면 `sw.js`의 `CACHE` 버전을 올릴 것.**
아이콘은 `python tools/make_icons.py`로 다시 생성.

## 플레이 방법

- **이동:** 화면 아무 곳이나 드래그. 손가락이 움직인 만큼 캐릭터가 따라감(상대 이동)이라 손가락에 캐릭터가 가려지지 않음.
- **DODGE (4마디):** 보스 탄막을 피함. 탄을 아슬아슬하게 스치면 **GRAZE 게이지**가 참.
- **COUNTER (캐치 포인트):** 4마디째 마지막 박에 음악이 끊기고 탄막이 멈춤. 다음 박에 드롭.
- **STRIKE (4마디):** 화면이 흑백 반전. 박자마다 생기는 약점 노드를 **드래그로 그어서** 벰.
  - 노드는 1.5박 전(FINISH는 2.5박 전)부터 보임
  - 순서 표시: 다음 노드는 진하게 + 박마다 맥동, 그다음은 반투명, 그 뒤는 흐리게. 다음 → 그다음 노드로 점선 화살표
  - 위치는 랜덤, 최소 여백: 정박 노드끼리 지름 1개, 4연타끼리 지름 0.5개, 보스(FINISH 자리)와 지름 1개
  - 정박 ±0.25초 안에 그으면 판정. ±0.08초 PERFECT / ±0.15초 GREAT / 나머지 GOOD
  - 마지막 마디는 8분 4연타 후 3박째 FINISH (보스 본체를 그어서 벰). 4연타는 관절 내각 150~170°로 한쪽으로 휘는 곡선, 두 번째 꺾임은 첫 꺾임 ±3° 이내 (지그재그 없음)
  - 대미지 = 판정 × GRAZE 배율 × 콤보
- **체력 5칸.** 맞으면 1칸 감소 + 1.5초 무적 + 주변 탄 정리.
- **회복:** 반격 구간 노드를 **하나도 안 놓치면(FULL COMBO) 체력 1칸 회복** (꽉 차 있으면 +500점).
- 보스 HP를 0으로 만들면 클리어.

### 난이도 메모
- 탄 실제 판정은 보이는 크기의 60% (`BULLET_HIT`), 레이저 판정 폭은 80%.
- 레이저 예고 2박(0.8초), 슬램 예고 2박.
- 난이도 단계(tier)는 곡마다 `songs.js`의 `tierBars`마디마다 상승, `maxTier`까지 (첫 곡: 36마디마다, 최대 2). 링 탄 개수·속도 증가, 레이저 추가.
- 첫 곡은 진입장벽 낮게: 보스 HP 1800, 최대 tier 2. 이후 곡일수록 어렵게.

## 음악 = 탄막

| 악기 | 회피 패턴 | 반격 페이즈 |
|---|---|---|
| 킥 | 보스에서 퍼지는 링 탄 | 노드 생성 타이밍 |
| 카우벨 | 음 높이 = 레이저 위치 (2박 전 예고) | — |
| 808 | 반화면 슬램 (2박 카운트다운) | 화면 흔들림 |
| 하이햇 | 플레이어 조준탄 (빌드업 마디) | — |

## 음악 모드

- **기본: Suno 곡** (`music/COUNTERBEAT #1.mp3`). 곡이 음악을 맡고, 게임은 DJ 필터로 공수를 표현: 회피 중엔 곡이 살짝 먹먹(로우패스 1.8kHz), 캐치 박에 필터를 닫으며 빨아들이고, 드롭 박에 활짝 열면서 킥을 얹음. `F` 키로 필터 끄면 곡은 항상 원음, 드롭 킥만 남음.
  - 장애물 소리: 레이저 = Railgun, 슬램 = Glitch Crush (고정, `game.js`의 `LASER_SFX`/`SLAM_SFX`). 후보는 [lab.html](lab.html)에서 미리듣기. 레이저는 멜로디 없음, 세로 레이저는 위치 따라 패닝.
  - 구간(회피/반격)은 [songs.js](songs.js)의 비트맵으로 정함: `[시작 마디, 타입]` 목록.
  - 회피 구간 마지막 마디 4박째 = 캐치 포인트. 반격 구간 마지막 마디 = FINISH. 회피는 최대 4마디.
  - 곡이 끝날 때까지 보스를 못 잡으면 TIME UP.
- **`?music=synth`: 내장 합성 비트.** `인트로 2마디 → [회피 4마디 → 캐치 → 반격 4마디] 반복`, 사이클마다 난이도 상승(최대 4단계).

현재 게임 그리드는 150 BPM 고정 (곡도 150 BPM이어야 함).

## 디버그 키

| 키 | 기능 |
|---|---|
| `G` | 무적 |
| `H` | 히트박스 / 그레이즈 범위 표시 |
| `F` | 공수 교대 DJ 필터 켜기/끄기 (저장됨) |
| `[` `]` | 오디오-화면 싱크 보정 ±10ms (저장됨) |
| `R` | 즉시 재시작 |
| `P` / `Esc` | 일시정지 |
| `?bar=N` | N마디부터 시작 (Suno 곡 기준 `?bar=22` → 첫 드롭 직전) |
| `?music=synth` | Suno 곡 대신 내장 합성 비트로 플레이 (고정 4+4 구조) |

## 구조

```
index.html   캔버스 + 스크립트 로드
lab.html     사운드 랩: 레이저/슬램 소리 후보 미리듣기
manifest.webmanifest, sw.js, icons/   홈 화면 앱(PWA)
tools/       아이콘 생성 스크립트
audio.js     WebAudio 합성 phonk 키트 + 곡 재생/덕킹
songs.js     곡 비트맵 (BPM, 첫 박 오프셋, 구간 목록)
music/       곡 파일
game.js      곡 구조, 스케줄러, 스폰, 판정, 렌더링, 입력
docs/        기획/음악 문서
```

- 기준 시계는 `AudioContext.currentTime` (프레임 시간 아님). 일시정지 = 오디오 컨텍스트 suspend.
- 오디오는 0.15초, 게임 오브젝트는 1마디 앞서 예약. 탄/레이저는 시간 함수라 결정적.
- 논리 해상도 540×960 (9:16 세로), 화면에 맞춰 스케일.
- 구간 진행도는 HUD 대신 배경 전체 게이지로 표시. 끝선이 박마다 맥동, 캐치 직전 마디는 경고색.
- 구간 게이지: 회피는 왼→오로 차오르고, 반격은 오→왼으로 빠짐.
- Suno 모드의 장애물 소리는 스폰 시점에 오디오 시간으로 미리 예약.
